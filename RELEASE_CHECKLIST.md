# Checklist de release

- [ ] `python -m unittest discover -s tests` aprovado.
- [ ] Verificação JavaScript aprovada para `desktop/main.cjs` e `frontend/runtime.js`.
- [ ] CRM, campanhas, follow-ups, biblioteca, copiloto, oferta, integração,
      status e pesquisa verificados.
- [ ] Navegador interno abre, retorna ao painel e preserva sessão.
- [ ] Monitor da página inicial detecta mensagens; seguidores são verificados.
- [ ] Nenhum token, banco, log, build ou `node_modules` será commitado.
- [ ] Instalador gerado e testado.
- [ ] Manual e changelog atualizados.
