# Runtime local do Agente de Vendas

Na versão instalada, esta pasta contém o `llama-server.exe` do llama.cpp e o
modelo local `qwen3-sales.gguf`.  Eles são iniciados pelo Electron e não
dependem de Ollama, BrowserOS ou de outro aplicativo aberto.

Os binários e os pesos do modelo não entram no Git: são artefatos de build.
